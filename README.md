# regional-rag-pilot

Regional RAG Pilot
==================

Formål
-------
At etablere en regional Knowledge Assistant for
systemadministratorer på billeddiagnostiske afdelinger
i Region Hovedstaden.

Målgruppe
----------
- PACS administratorer
- RIS administratorer
- Infrastruktur teams
- Integrationsteams

Datakilder
-----------
- SharePoint
- ServiceNow
- Leverandørmanualer
- SOP'er
- Change Records
- Incident historik

Teknologi
-----------
- Databricks
- Unity Catalog
- AI Search
- Mosaic AI Agent Framework

MVP
----
Fokus på PACS- og RIS-dokumentation fra Herlev Hospital.
